How Windy works

It notices first, and you stay in control.

"We have the transactions. But then what can we do with them?" The bank already holds the data that shows when a plan is about to break. Today it just lists it.

Notices

Spots a life change, a gap before payday, a new bill or a price rise in your transactions.

Works it out

A Python engine calculates the options: goal dates, auto-saves and a 5-week forecast.

Explains

The AI explains the result in two or three plain sentences, using only the engine's numbers.

You decide

Nothing changes until you approve, and every change can be undone.

One engine for every number

Plans, goal dates and the forecast come from the same calculator, so the same question always gets the same answer.

The AI only explains

It gets a summary of the change, never raw transactions or account numbers. In chat it calls 12 tools over the live plan, so it can look things up, not make them up.

A plan you can trust

Approvals are saved in SQLite with history, undo, and a log of what Windy used. Windy also remembers past chats and lasting notes.

Safe by design

Every answer is checked before Mia sees it.

Consent first

Each feature has its own switch. Turn one off and the backend refuses to run it, not just the screen.

Numbers come from the calculator

Every figure in an AI sentence must match the engine, or a safe template is used instead.

Financial checks

Emergency fund untouched, no account below $0, moves between Mia's accounts add up to zero.

Stays in its lane

No product picks or financial advice, and no health or diet talk drawn from purchases.

Nothing moves without approval

Approving only changes the simulated plan, and every change can be undone.

Try it

Runs on your laptop in one command.

Needs Node 18+ and Python 3.10+. Without an API key Windy falls back to its built-in explanation templates, which pass the same checks.

Open the repository Team TrustByte
